# Romantic Flower Project — Master

## Included
- Gift intro with opening animation
- Original flower SVG preserved
- Memory cards
- Animated envelope + typed letter
- Live relationship timer
- Music control placeholder
- Romantic final screen
- Custom heart cursor and click effects
- Responsive mobile layout

## Quick customization
1. Replace the three memory placeholders in `index.html` with your photos.
2. Edit the letter text inside `script.js`.
3. Change `startDate` inside `script.js` to the real date.
4. Put your music file beside the project and connect it in `script.js`.
